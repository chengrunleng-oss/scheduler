# 任务工作台

一个本地优先的任务管理器，用文件夹、状态和不同视图整理工作，同时保留清晰的任务详情与数据备份能力。

## 本地开发

安装依赖后启动开发服务器：

```bash
npm install
npm run dev
```

然后访问终端显示的地址，默认是 `http://127.0.0.1:5173/`。Vite 会处理 TypeScript、HTML 和 CSS 的热更新，不需要手动修改资源版本号；如果 5173 已被占用，Vite 会自动选择后续可用端口。

也可以明确指定端口：

```bash
npm run dev -- --port 5200
```

如需按正式构建结果运行：

```bash
npm run build
npm run preview
```

页面使用 ES Modules，不建议通过 `file://` 直接打开。

## 当前功能

- 新建任务：侧栏提供全局入口，根级操作位于任务树末尾，文件夹标题支持就地创建；任务和文件夹录入均支持 Enter 保存、Escape 取消。
- 任务编排：任务树内可通过拖拽或更多操作完成同文件夹排序、跨文件夹移动和优先级调整；高/低分界线也可直接拖动。
- 逾期处理：严格早于今天的待办进入文件夹顶部逾期区，可快捷改到明天、3 天后、7 天后或自定义日期。
- 三态管理：完成或丢弃后保留 8 秒原位撤销窗口，待办筛选和刷新均不会丢失计时；确认后进入文件夹末尾的虚拟“已处理”区。
- 任务详情：可编辑名称、说明、优先级、截止日期、标签和文件夹，并查看完整改期时间线。
- 文件夹树：支持四层嵌套、新建、重命名、移动、独立导航折叠和两种非空文件夹删除策略。
- 四种视图：任务树、全局优先级、全局日期、优先级＋日期共享搜索、状态筛选和文件夹范围；全局任务可一键在树中定位。
- 数据保护：支持撤销/重做、JSON 导入导出、schema v4 校验，以及 v1/v2/v3 本地数据和备份迁移。
- 响应式布局：宽屏在选中任务后显示三栏详情，常见桌面与平板使用详情抽屉，手机使用导航抽屉和全屏详情。
- 显示设置：支持跟随系统、浅色和深色主题，视图、筛选、默认新任务值和折叠偏好会在刷新后恢复。

数据保存在当前浏览器的 `localStorage` 中。导入会在确认后替换当前数据，并清空普通撤销/重做历史。

## 文档目录

- `README.md`：使用方式、当前功能和工程入口。
- `ENGINEERING_REVIEW.json`：本轮升级采用的最新改进反馈、产品决策和验收标准。
- `TEST_FEEDBACK.json`：最新浏览器验收结果、已知问题和后续建议。
- `ITERATION_LOG.md`：各版本实现与验证记录。
- `BRANCHING.md`：分支和提交约定。
- `dist/`：由 Vite 生成并带内容哈希的正式浏览器构建产物。

## 工程结构

- `src/domain.ts`：schema v4、旧版迁移、校验、日期分组、视图排序和文件夹约束。
- `src/store.ts`：原子移动、待决处理、改期时间线、撤销/重做和 no-op 保护。
- `src/storage.ts`：本地保存、旧版本 fallback 和备份导入导出。
- `src/ui/`：选择器、渲染、事件、弹窗、Lucide 图标和 Pragmatic DnD 拖拽控制。
- `vite.config.mjs`：Vite 开发服务器、正式构建和本地预览配置。
- `tests/`：领域、状态、存储和关键 UI 契约回归测试。
- `e2e/`：真实浏览器交互和桌面、手机视口回归测试。

## 验证

首次运行浏览器测试时安装 Chromium：

```bash
npx playwright install chromium
```

```bash
npm run verify
```

也可以分步运行 `npm run typecheck`、`npm test`、`npm run check:dist` 和 `npm run test:e2e`。持续集成会安装 Chromium 并执行同一套 `verify` 验证。
