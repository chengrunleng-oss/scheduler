# 任务工作台

一个本地优先的任务管理器，用文件夹、状态和不同视图整理工作，同时保留清晰的任务详情与数据备份能力。

## 使用方式

安装依赖并构建后，用本地静态服务器运行：

```bash
npm install
npm run build
npm run serve
```

然后访问 `http://localhost:5173/`。页面使用 ES Modules，不建议通过 `file://` 直接打开。

## 当前功能

- 快速新增：记录任务名称、优先级、截止日期、文件夹和标签。
- 任务详情：选中任务后编辑名称、说明、状态、优先级、截止日期、标签和文件夹；创建与更新时间只读显示。
- 三态管理：任务可在待办、已完成、不再需要之间流转，状态变化不会删除任务内容。
- 行内操作：支持完成、标记不再需要、恢复待办、提高/降低优先级和可撤销删除。
- 文件夹树：支持四层嵌套、新建、重命名、移动、折叠和两种非空文件夹删除策略。
- 多视图：树状、优先级和截止日期视图共享搜索、状态筛选和文件夹范围。
- 数据保护：支持撤销/重做、JSON 导入导出、schema v3 校验，以及 v1/v2 本地数据和备份迁移。
- 响应式布局：桌面使用三栏详情，平板使用详情抽屉，手机使用导航抽屉和全屏详情。
- 显示设置：支持跟随系统、浅色和深色主题，视图、排序、筛选和折叠偏好会在刷新后恢复。

数据保存在当前浏览器的 `localStorage` 中。导入会在确认后替换当前数据，并清空普通撤销/重做历史。

## 工程结构

- `src/domain.ts`：schema v3、迁移、校验、筛选排序和文件夹约束。
- `src/store.ts`：状态动作、撤销/重做和 no-op 保护。
- `src/storage.ts`：本地保存、旧版本 fallback 和备份导入导出。
- `src/ui/`：选择器、渲染、事件、弹窗与 DOM 工具。
- `tests/`：领域、状态、存储和关键 UI 契约回归测试。
