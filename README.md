# 计划记录工作台

一个本地可用的计划记录软件，用来快速记录将要做什么，并在每轮迭代结束后沉淀完成记录、下一轮建议和用户反馈。

## 使用方式

直接用浏览器打开 `index.html`。

数据会保存在当前浏览器的 `localStorage` 中，刷新页面不会丢失。点击“导出”可以备份当前数据为 JSON 文件。

## 当前功能

- 新增计划：支持内容、优先级、日期、标签。
- 管理计划：支持搜索、按状态筛选、编辑、删除、完成状态切换。
- 今日概览：显示待办、完成、高优先级数量。
- 迭代记录：可维护本轮完成记录、下一轮建议，并归档到迭代历史。
- 反馈输入：输入你的建议后，会自动生成下一轮计划项，并同步生成一条高优先级反馈任务。

## 迭代方式

每轮开发完成后查看 `ITERATION_LOG.md`。你可以直接反馈下一轮想改什么，我会基于反馈继续进入下一轮开发。
