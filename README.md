# 任务工作台

一个本地优先的任务管理器，用文件夹、状态和不同视图整理工作，并在任务工作区中维护长期说明、每日工作记录和附件。

## 本地开发

安装依赖后启动开发服务器：

```bash
npm install
npm run dev
```

然后访问终端显示的地址，默认是 `http://127.0.0.1:5173/`。Vite 会处理 TypeScript、HTML 和 CSS 的热更新，不需要手动修改资源版本号；如果 5173 已被占用，Vite 会自动选择后续可用端口。

也可以明确指定端口：

```bash
npm run dev -- --port 5200
```

如需按正式构建结果运行：

```bash
npm run build
npm run preview
```

页面使用 ES Modules，不建议通过 `file://` 直接打开。

## 当前功能

- 新建任务：侧栏提供全局入口，根级操作位于任务树末尾，文件夹标题支持就地创建；任务和文件夹录入均支持 Enter 保存、Escape 取消。
- 任务编排：任务正文、标签和六点图标均可拖拽，支持同文件夹排序、跨文件夹移动和优先级调整；拖动期间会实时显示等高落点并让相邻任务平滑让位，取消后恢复原顺序。
- 优先级分区：高/低任务使用暖色与冷色整行分区，悬停和选中后仍保留所属色系；双色阈值标记支持鼠标、触屏和键盘调整分界。
- 逾期处理：严格早于今天的待办进入文件夹顶部逾期区，可快捷改到明天、3 天后、7 天后或自定义日期。
- 三态管理：完成或丢弃后保留 8 秒原位撤销窗口，待办筛选和刷新均不会丢失计时；确认后进入文件夹末尾的虚拟“已处理”区。
- 任务工作区：概览、工作记录、附件三个标签页；宽屏使用零重叠三栏布局和紧凑两行任务卡，常驻调节轨道可调宽并记忆，常规桌面替换任务列表，手机全屏显示。
- Markdown 工作记录：Milkdown Crepe 提供所见即所得编辑，长期描述与按日记录分别自动保存；支持进度、历史日期、倒序历史、新建编辑删除、8 秒删除撤销、只读状态和源码＋预览后备模式。
- 本地附件：支持文本、图片、PDF 和常见办公/二进制文件；可导入描述或每日记录、预览、打开、重命名、导出，并将图片引用插入 Markdown。
- 文件夹树：四层嵌套使用不同深度的便签式视觉层级；支持新建、重命名、选择父级与同级位置的精确移动、独立导航折叠、删除影响预览和两种非空文件夹删除策略。
- 四种视图：任务树、全局优先级、全局日期、优先级＋日期共享搜索、状态筛选和文件夹范围；全局任务可一键在树中定位。
- 数据保护：schema v5 保留 v1-v4 迁移能力；完整 ZIP 备份包含任务状态、工作记录 Markdown 和原始附件，同时仍可导入旧 JSON 备份。
- 响应式布局：宽屏在选中任务后显示三栏详情，常见桌面与平板使用详情抽屉，手机使用导航抽屉和全屏详情。
- 显示设置：支持跟随系统、浅色和深色主题，视图、筛选、默认新任务值和折叠偏好会在刷新后恢复。

任务、文件夹和偏好保存在当前浏览器的 `localStorage` 中；工作记录、附件元数据和 Blob 保存在 IndexedDB 中。导入会在完整校验和确认后替换两处数据，并清空普通撤销/重做历史。

## 文档目录

- `README.md`：使用方式、当前功能和工程入口。
- `ENGINEERING_REVIEW.json`：本轮升级采用的最新改进反馈、产品决策和验收标准。
- `TEST_FEEDBACK.json`：最新浏览器验收结果、已知问题和后续建议。
- `ITERATION_LOG.md`：各版本实现与验证记录。
- `BRANCHING.md`：分支和提交约定。
- `dist/`：由 Vite 生成并带内容哈希的正式浏览器构建产物。

## 工程结构

- `src/domain.ts`：schema v5、旧版迁移、校验、日期分组、视图排序和文件夹约束。
- `src/store.ts`：原子移动、待决处理、改期时间线、撤销/重做和 no-op 保护。
- `src/storage.ts`：轻量状态保存、旧版本 fallback 和旧 JSON 导入。
- `src/workspace-db.ts`：工作记录、附件元数据和附件 Blob 的 IndexedDB 仓库。
- `src/backup.ts`：完整 ZIP 备份生成、校验和恢复。
- `src/ui/`：选择器、渲染、事件、任务工作区、Markdown 编辑器、弹窗、Lucide 图标和 Pragmatic DnD 拖拽控制。
- `vite.config.mjs`：Vite 开发服务器、正式构建和本地预览配置。
- `tests/`：领域、状态、存储和关键 UI 契约回归测试。
- `e2e/`：真实浏览器交互和桌面、手机视口回归测试。

## 验证

首次运行浏览器测试时安装 Chromium：

```bash
npx playwright install chromium
```

```bash
npm run verify
```

也可以分步运行 `npm run typecheck`、`npm test`、`npm run check:dist` 和 `npm run test:e2e`。持续集成会安装 Chromium 并执行同一套 `verify` 验证。
