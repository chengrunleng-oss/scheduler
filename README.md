# 任务记录工作台

一个本地可用的任务记录软件，用来快速记录将要做什么，并在每轮改进后沉淀完成记录、下一轮建议和用户反馈。

## 使用方式

直接用浏览器打开 `index.html`。

数据会保存在当前浏览器的 `localStorage` 中。点击“导出”可以备份当前数据为 JSON 文件，点击“导入”可以恢复备份。导入是确认替换数据的操作，不进入普通撤销历史。

## 当前功能

- 任务记录：支持内容、优先级、截止日期、标签。
- 任务管理：支持搜索、按状态筛选、完整编辑、删除、完成状态切换。
- 任务概览：显示待办、完成、到期/逾期数量。
- 改进记录：可维护本轮完成记录、下一轮改进项，并归档到开发历史。
- 产品反馈：输入建议后，会整理为下一轮改进项，并生成一条高优先级反馈任务。
- 数据保护：支持导出、导入、基础 schema 校验和旧数据迁移。
- 使用体验：支持撤销/重做、系统/浅色/深色主题、页面内弹窗。

## 工程结构

- `src/`：TypeScript 源码，按类型、领域逻辑、状态、存储、UI 拆分。
- `dist/`：由 `src/` 自动构建生成的浏览器运行产物，不再手工维护。
- `tests/`：Node 内置测试框架的回归测试。

## 验证

```bash
npm install
npm run verify
```

也可以分步运行：

```bash
npm run build
npm run typecheck
npm test
```

依赖安装并执行 `npm run build` 后即可运行。当前页面加载 ES Modules，建议用本地静态服务器打开，例如在项目目录执行 `python -m http.server 5173` 后访问 `http://localhost:5173/`。
